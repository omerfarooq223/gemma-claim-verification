# Official Competition Datasets

Place raw competition files in this directory when reproducing experiments locally:

- `train.jsonl` (Expected SHA-256: `26ea9a6998815d0f99f45aff2206f435781cc71bd92638101d7ea08c2e175d3c`)
- `validation.jsonl` (Expected SHA-256: `722a5f111693996369a02d26eda08f00cdfb51f5b8b842addb752814f03716c9`)
- `test.jsonl` (Expected SHA-256: `8811c713e4297c0ce6e89a020d212621af538c74fa3866f4b5d98914ca3b8a28`)

> [!NOTE]
> These files are ignored by Git to adhere to competition privacy terms. Verify downloaded files using `python scripts/verify_artifact.py <filepath> --key <key>`.
