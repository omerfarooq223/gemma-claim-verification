# Pre-Hackathon Rehearsal Datasets

Prior to receiving the official hackathon competition data, preliminary exploration was conducted on practice benchmarks (such as **PakAssist** English-Urdu intent routing and synthetic rehearsal tasks).

These experiments allowed the team to:
1. Rehearse end-to-end QLoRA training and GPU memory constraints on NVIDIA T4.
2. Establish robust response-only loss masking and chat template formatting.
3. Validate deterministic evaluation and error analysis pipelines.

These pre-hackathon datasets were **not** used to train the final competition claim-verification checkpoint.
